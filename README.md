# soc-home-lab-wazuh

Projeto de laboratório de detecção e resposta (Blue Team) com Wazuh, Sysmon e simulações controladas mapeadas ao MITRE ATT&CK.

> ⚠️ Este é um projeto de laboratório, executado em ambiente isolado, em máquinas virtuais minhas. Não envolve sistemas de terceiros nem malware real.

## Objetivo
Montar um mini SOC para praticar triagem de alertas, criação de regras de detecção e escrita de relatórios de incidente.

## Status
🚧 Em andamento

## Estrutura planejada
- `architecture/`: diagrama e descrição do lab
- `configs/`: configurações (sem senhas)
- `detections/`: regras de detecção próprias
- `attack-simulations/`: simulações controladas e tabela ATT&CK
- `incident-reports/`: relatórios de incidente
- `screenshots/`: evidências
